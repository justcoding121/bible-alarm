# Android (Play Store) store listing text

Use the **short** description for the Play Store "Short description" (80 characters max).  
Use the **long** description for the "Full description" (4000 characters max).  
The language list is derived from the media index DB (Bible category, `PublicationLanguages`).

**Full description formatting:** The Play Store does **not** support Markdown (`**bold**`, `-` bullets). Use:
- **Bold:** `<b>text</b>`
- **Bullets:** type the bullet character `•` (U+2022) or use `<ul><li>...</li></ul>`
- Plain line breaks and punctuation are fine.

## Long description

Make your New World Translation (NWT) Bible listening schedule easy: set it as an alarm or play on demand when you have time. Optionally start with music before the scheduled Bible reading. Chapters and verses resume where you left off.

**Features:**
- Recurring alarms with your choice of Bible publication and language
- Optional "begin with music"
- Stream or download; playback continues in the background
- **Android Auto** support: play and control Bible and music from your car
- System media controls and lock-screen controls
- Resume by chapter and verse
- No ads; non-commercial and free

Audio is available in **over 240 languages**, streamed or downloaded from jw.org. At present, only the New World Translation (NWT) is available for Bible reading.

This app is non-commercial and free, with no advertisements; the publisher does not gain and does not intend to gain anything monetarily. The app adheres to the terms of use for third-party apps as stated on jw.org (Jehovah’s Witnesses).

## Regenerating the language list

To refresh the list from the current media index (e.g. after re-running the cataloger):

```bash
dotnet run --project .tools/Bible.Alarm.DbMigration -- list-bible-languages
```

Optional: pass a path to `index.zip` or the folder containing `mediaIndex.db`:

```bash
dotnet run --project .tools/Bible.Alarm.DbMigration -- list-bible-languages "c:\path\to\.tools\_index"
```
